# Nova Studio Web Sitesi

Bu depo, hızlı bir şekilde kullanılabilen modern bir başlangıç web sitesi içerir.

## Özellikler

- Mobil uyumlu tasarım
- Temiz ve modern arayüz
- Hero alanı, hizmetler ve iletişim bölümleri
- GitHub Pages için uygun statik yapı

## Yerel olarak çalıştırma

```bash
python -m http.server 8000
```

Ardından tarayıcıda şu adrese gidin:

```text
http://localhost:8000
```

## GitHub Pages için yayınlama

1. GitHub depoda `Settings` sekmesine gidin.
2. `Pages` bölümüne geçin.
3. `Deploy from a branch` seçeneğini seçin.
4. Branch olarak `main` ve folder olarak `/root` seçin.
5. Kaydettiğinizde site yayınlanacaktır.

## Dosya yapısı

- `index.html` - Ana sayfa
- `styles.css` - Stil dosyası
- `script.js` - Küçük etkileşimler

İsterseniz bir sonraki adımda bunu kişisel portföy, şirket tanıtım sayfası veya e-ticaret temasına dönüştürebilirim.
